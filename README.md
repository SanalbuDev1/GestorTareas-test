Se debe crear un ACR el acr va almacenar la imagen del docker
luego se debe crear un ACI (Azure Container Instance) para ejecutar la imagen

pasos
1. Se debe crear la imagen docker

docker-compose build

2. luego se debe llevar a azure

docker tag appdocker-compose-webflux:<tag> <acr-name>.azurecr.io/<image-name>:<tag>
docker push <acr-name>.azurecr.io/<image-name>:<tag>

3. luego se ejecuta el comando para crear el ACI

az container create \
  --resource-group test-azureapps \
  --name appdocker-compose-webflux \
  --image hellotareas.azurecr.io/appdocker-compose-webflux:latest \
  --cpu 1 \
  --memory 1.5 \
  --registry-login-server hellotareas.azurecr.io \
  --registry-username hellotareas \
  --registry-password 9+mWYoUOj85NoEkbV9E7qY6fgwBO90VMBi4T84jdFf+ACRB8Pr0S \
  --dns-name-label mycontainers \
  --ports 8082
